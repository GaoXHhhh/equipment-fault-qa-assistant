# 技术说明

面向想跑起来、改代码或讲清流程的人。功能与应用场景见仓库首页 `README.md`。

## 1. 目录结构

```
设备故障问答助手/
├── app/
│   ├── main.py          # FastAPI 路由：上传、切片、检索、SSE 问答、反馈
│   ├── config.py        # 环境变量 / 注册表 / .env 读取，切片与模型参数
│   ├── db.py            # SQLite：documents / chunks / tickets / feedback
│   ├── ingest.py        # 五格式解析 + 切片 + 结构化工单抽取
│   ├── agent.py         # 意图解析 + 工具路由（工单库 / 知识库）
│   ├── retrieval.py     # 分词、同义词等价组、BM25、本地 n-gram 语义、RRF 融合
│   ├── llm.py           # DeepSeek 流式调用 + 提示词 + 演示模式兜底
│   └── static/          # 原生 HTML/CSS/JS，无构建步骤
├── 示例知识库/           # 5 份模拟文档，首次启动自动入库
├── tools/make_samples.py # 重新生成示例知识库
├── docs/                # 截图与本文档
├── data/                # 运行时生成：kb.sqlite3、uploads/、日志
├── run.bat              # 装依赖 + 开发模式启动（--reload）
├── start_server.bat     # 正式启动，日志写 data/server.log
├── start_hidden.vbs     # 无窗口后台启动
└── stop_server.bat      # 结束占用 8000 端口的进程
```

## 2. 文档解析与切片

| 格式 | 解析方式 | 来源定位 |
| --- | --- | --- |
| PDF | pypdf 逐页提取文字 | 页码 |
| Word | python-docx 段落 + 表格，按 Heading 分节 | 章节名 / 表格序号 |
| Excel | openpyxl 按工作表读取，每行独立成块（自带列名）；表头含“工单号”时同时抽取结构化记录 | 工作表 + 行号 |
| CSV | 编码探测（UTF-8 / GBK）后按行独立成块 | 行号 |
| TXT / MD | Markdown 按标题分节；FAQ 按 `Q1/Q2…` 分段 | 章节 / 问题标题 |

切片顺序：段落 → 句子 → 合并 → 尾部重叠，默认 520 字、80 字重叠，避免把一条排查步骤从中间切断。FAQ 按题切分，引用能精确到具体问题。

## 3. 检索

- jieba 搜索模式分词，叠加领域同义词等价组（刷卡/读卡/读卡器、结算台/收银机/一体机、称重/秤/传感器、掉线/断网/离线…）。
- 实体归一化：`2025.5.7` / `2025/5/7` / `2025年5月7日` → `2025-05-07`；`5月7日` → `05-07`；`E05`、`PS-2025-0506` 单独成 token，避免被拆成单数字。
- 通道一：BM25（k1=1.5，b=0.75）；通道二：本地字符语义（字符 2/3-gram 经哈希映射到 1024 维、IDF 加权的 L2 向量，余弦相似度）。同义词扩展通过 `semantic_query_text()` 同时注入两个通道。
- 两通道各自排名后用 RRF（k=60）融合：`score = 1/(60+rank_bm25) + 1/(60+rank_semantic)`，再做实体/文件名加权；替代旧版线性加权，避免分数尺度不一致互相压制。
- 工单库现象检索用 `ticket_keyword_groups()`：只保留部件词本身命中的同义组，组内 OR、组间 AND，防止泛词放大统计。
- Top-K 默认 5，来源卡片展示每片匹配度。

## 4. 两段式问答

```
用户问题
  → ① 规则抽取：日期、工单号、故障码
  → ② DeepSeek 解析：JSON 输出 intent / rewritten_query / keywords / year / 日期 / 工单号 / 故障码 / 客户
       （8 秒超时，结果缓存 10 分钟；失败自动退回正则）
  → ③ 条件合并 + 工具路由
       query_tickets：SQLite 精确查工单、按故障码统计
       search_kb：BM25 / 混合检索
       命中工单时，知识库剔除重复工单切片，只补手册与 FAQ 的排查步骤
  → ④ 工具结果按 [1][2] 编号注入提示词 → DeepSeek 流式生成
  → ⑤ SSE 推送：plan → sources → delta → done
```

| 意图 | 触发示例 | 工具 |
| --- | --- | --- |
| 工单查询 | 2025.5.7 有哪些设备出过故障 / PS-2025-0506 根因是什么 | query_tickets + search_kb |
| 故障统计 | E18 一共出现过几次 / 刷卡不识别 2025 年出现几次 | query_tickets（故障码或现象关键词组统计）+ search_kb |
| 故障排查 | 称重数值一直跳怎么处理 | search_kb |
| 部署咨询 | 银行内网部署要注意什么 | search_kb |
| 知识检索 / 闲聊 | 支持哪些菜品 / 你好 | search_kb |

工程约束：

- 解析、工具、生成三段分开，工具调用是确定性的，模型只做理解与组织语言。
- 明显条件由正则先抽，模型解析只做补充，避免模型漏抽导致查不到。
- 只说“5月7日”不带年份时按“月-日”匹配，可能命中不同年份的同一天；当前数据只有 2025 年。

## 5. 回答约束

- 只依据参考资料，先结论后编号步骤，关键结论标 `[1]`。
- 资料不足要明说；按日期/工单号查询要逐条列工单明细；银行场景提示数据不出内网。
- 工单无命中时注入覆盖范围（如“工单库共 31 条，覆盖 2025-01-06 至 2025-10-08”），避免编造。
- 未配置 Key 时进入演示模式：规则解析 + 工具照常调用，回答退化为原文摘录，链路仍完整。

## 6. 反馈

`feedback` 表记录问题、答案、是否有用、补充说明、引用文档名；`/api/feedback/stats` 返回总数、有用率、待优化数、最近记录。

## 8. Key 读取优先级

1. 进程环境变量（大小写不敏感，兼容 `DEEPSEEK_API_KEY` / `deepseek_api_key`）
2. Windows 注册表（HKLM / HKCU Environment）
3. `.env`

空值与 `sk-xxxx` 占位符会被忽略；`/api/config` 的 `key_source` 可确认来源（`system_env` / `system_registry` / `.env`）。

注意：`.env` 只能写 `key=value`，不能写 `os.environ.get(...)` 这类代码，否则会被当成普通字符串。

## 9. 可选：外部 Embedding

默认使用本地字符 n-gram 语义向量，无需任何 Key 即可混合检索。如需外部 Embedding：

```ini
EMBEDDING_PROVIDER=dashscope          # 或 openai_compatible
EMBEDDING_API_KEY=sk-xxx              # DashScope 可用 DASHSCOPE_API_KEY
EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
EMBEDDING_MODEL=text-embedding-v4
```

开启后需重新入库（删 `data/kb.sqlite3` 重启，或重新上传），否则旧切片没有外部向量；本地 n-gram 通道仍会保留并参与 RRF 融合。

## 10. 数据重置

```bat
REM 先停止服务，再删数据库；重启会自动重新入库示例知识库
del data\kb.sqlite3
python -m uvicorn app.main:app --port 8000
```

注意：删库会同时删掉已上传文档与工单记录。

## 12. 已知限制

- 扫描件 PDF（图片型）无 OCR，需用可复制文字的版本。
- 旧版 `.doc` / `.xls` 需先另存为 `.docx` / `.xlsx`。
- 结构化工单要求表头能识别（含“工单号”，字段 ≥ 3）；自定义表头在 `ingest.TICKET_FIELDS` 补别名。
- 意图解析每题多一次模型调用（约 1–2 秒），有缓存；失败退回正则。
- 裸写 `5.7` 不识别为日期，请写 `2025.5.7` 或 `5月7日`。
- SQLite + 内存 BM25 适合千级切片、单机演示；生产建议 PostgreSQL + 向量库并加权限与审计。
- 默认只监听 `127.0.0.1`，无登录鉴权，不要直接暴露公网。
- 示例数据均为虚构，仅用于流程演示。

## 14. 上线要点（未执行，仅参考）

- 国内云主机 2C2G 起步，Nginx 反代 + HTTPS（certbot），域名需 ICP 备案。
